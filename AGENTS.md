# Repository maintenance

When changing implementation, update `documentation-checklist.md` with the affected
Markdown files, diagrams and concrete pending edits. The user prefers the full
documentation reconciliation immediately before a requested push, rather than
rewriting every document during each intermediate code change.

Before pushing, review and complete applicable checklist items against the final
diff. Keep `how-to-run.md` as the canonical run guide. The obsolete `how-to-run.txt` was removed.
Preserve proposal documents and RDF/index files. These instructions do not require
extra user approval and do not authorize an otherwise unrequested push.
